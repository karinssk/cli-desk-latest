When do notifications fire?

Sound — plays for background sessions. If you're viewing the session, no sound.

Dispatch — plays when `clideck ask` sends work into another agent.

Browser — only when the CliDeck tab is not in focus.

Mute — right-click a session to mute notifications and dispatch cues for it.
